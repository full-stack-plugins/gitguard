# ADR: optional Git executor remains disabled

The default Cargo feature set is empty. The historical generic `execution::request` remains denied. A separate explicitly invoked local CAS library slice is described in [local-atomic-apply.md](local-atomic-apply.md); it requires the `privileged-execution` feature and enabled configuration, fresh external grant validation and durable admission. `execution::ExecutionConfig` defaults to enabled=false and denies unknown fields. A request for CreateWorktree, CreateBranch, Push or Merge returns Disabled unless both feature and config are set; even then it returns AuthorizationUnavailable because no reviewed external authorization provider exists.

No mutation transport is routed through the generic request entrypoint. No production credential loader, signer or external identity service is supplied. This deliberately always-denied boundary is the supported behavior of task 4.1, not an emulated successful write. ALLOW, FlowGuard gate results, Markdown accepted, approved=true and authorizationReviewed=true cannot enable it; those extra configuration fields are rejected. Tests also produce a real engine ALLOW while source refs/index/worktree bytes remain unchanged and the merge port still rejects.

A future executor requires separate review of external issuer/actor/action/repo/exact candidate/expected target, immutable policy/approval binding, clock/expiry/revocation, credential scope, atomic target preconditions, durable intent and uncertain-write recovery before code can replace this denial. Read-only Git observation credentials must remain absent; any execution credential would come from that separately reviewed controller and never from a candidate/report Boolean. No provider, trust root, key storage or release authorization is selected here. A read-only task4.2 grant-validation library is implemented for independent review (see operation-grants.md); it does not link into this executor. Task4.4 now supplies the separate durable intent store. Task4.3 has only the opt-in local bare CreateBranch/fast-forward Merge subset for independent review; remote Push and CreateWorktree remain unsupported. Task4.5 receipt/history reconciliation remains unimplemented.
