# Local advisory vector

`local-sha1.json` is generated from a real Git repository with one `a` file containing `base\n`, mode 100644, commit message `base`, Fixture <fixture@example.invalid> author/committer and both dates `2000-01-01T00:00:00Z`. The integration test reconstructs the repository, compares the whole JSON value, and verifies the actual commit and digest. This fixture has no authenticated controller, approval, queue event or baseline.
